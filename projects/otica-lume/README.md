# Óticas Gaffa

Landing page estática demonstrativa, em português, criada para uma ótica fictícia. Abra `index.html` ou sirva esta pasta em um servidor HTTP. Não requer instalação ou compilação.

Para gerar a pasta de publicação `dist`, execute `node build.cjs` nesta pasta. O script também verifica referências locais e âncoras de navegação.

## Recursos

- Layout responsivo, menu móvel, links de navegação e perguntas expansíveis.
- Coleção com filtros e detalhes em diálogo nativo, com fechamento por Escape.
- Foco visível, link de salto, imagens descritas e respeito a movimento reduzido.
- Não coleta dados, não agenda atendimentos e não realiza vendas.

## Skills aplicadas

- [emil-design-eng](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md): transições específicas, feedback ao pressionar, hover restrito a dispositivos compatíveis e movimento reduzido.
- [landing-page-design](https://github.com/skills-101/superpowers/blob/main/guides/design/landing-page-design/SKILL.md): proposta clara na primeira tela, chamada para ação, sequência de conteúdo e alvos de toque acessíveis. Aplicadas as orientações de design; não foi necessário executar o serviço inference.sh.
