# Tavares Estética Automotiva

Landing page em HTML, CSS e JavaScript puro. Abra `index.html` ou rode um servidor local.

Edite `js/config.js` para preencher WhatsApp, Instagram, telefone, endereço, horários, serviços e fotos. Substitua os arquivos em `assets/images/` mantendo os nomes ou atualize os caminhos no config. O projeto funciona no GitHub Pages, Netlify e Vercel.
